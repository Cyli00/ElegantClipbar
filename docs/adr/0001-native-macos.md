# 迁移为 macOS 原生应用

ElegantClipbar 从 React、Tauri 和 Rust 迁移为 Swift 与 SwiftUI，仅面向 macOS，以减少技术栈和依赖，并采用原生系统交互。界面的布局、尺寸和交互尽量参照 ClashBar；最低支持 macOS 13，同时支持 Apple Silicon 和 Intel。

新版从空历史开始，不实现旧版历史和备份的迁移。保留文本、链接、HTML/RTF 富文本、图片和文件，整理功能仅保留搜索、预览和置顶，不保留独立收藏、分组、拖拽排序、文本编辑、多选合并及数字快捷粘贴。

保留开机启动、来源应用识别、应用排除、新版本地备份导入导出和音效，外观跟随系统明暗模式。移除 WebDAV 同步、翻译、工具栏定制及自定义主题，以减少独立设置页和后台服务。

面板固定在菜单栏图标下方，默认全局唤醒键为 Option+Command+V。点击记录或按回车后关闭面板，回到此前的应用并自动粘贴；未获得辅助功能权限时提供复制操作和授权提示。

文件历史仅保存文件位置，不复制原文件。普通历史默认最多 1,000 条、保留 30 天，超过任一限制即清理；置顶记录不参与自动清理。内容及格式完全相同时才去重并移到最新位置，相同文字但格式不同的记录分别保留。

记录成功与执行粘贴的音效各有独立开关，默认都关闭，保留试听并去掉音效时机选项。
